# Security Policy

## Scope
`mcp-audit` is an offline, zero-dependency static security scanner and cryptographic lockfile verifier for Model Context Protocol (MCP) server configurations and tool schemas. It never makes outbound network requests and never writes secret values into lockfiles.

## Reporting a Vulnerability
If you discover a bypass, false negative in steganography/injection detection, or security issue in `mcp-audit`, please open a GitHub Security Advisory on this repository rather than filing a public issue with exploit details.
